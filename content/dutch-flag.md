Edsger Dijkstra's classic problem: given an array of just three values
(red, white and blue paint, say), sort it in a single linear pass using
three pointers, `low`, `mid` and `high`, instead of a general-purpose sort.
Edit the array directly or randomize one below, then step through the
swaps.
